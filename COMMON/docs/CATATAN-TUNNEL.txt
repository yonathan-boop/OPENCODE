4. MASALAH & SOLUSI
------------------------------

MASALAH #1: HTTP 500 - "baseURL is not a valid URL"
  Gejala: E-Rapor error 500 saat diakses via Cloudflare Tunnel
  Penyebab: dirname() di Windows menghasilkan backslash (\),
            jadi URL-nya: http://domain.trycloudflare.com\/ (gak valid)
  Lokasi file: C:\newappraporsd2025\wwwroot\app\Config\Constants.php
  Baris 80 (aslinya):
    $base=... dirname($_SERVER['SCRIPT_NAME']);
  Solusi: tambah str_replace('\\','/', ...)
    $base=... str_replace('\\','/', dirname($_SERVER['SCRIPT_NAME']));

MASALAH #2: Mode Lite (CSS/JS gak loading)
  Gejala: Halaman kebuka tapi polosan, tanpa styling
  Penyebab: Cloudflare kirim HTTPS ke user, tapi kirim HTTP ke server.
            PHP detek $_SERVER['HTTPS'] = off, jadi base URL pake http://
            Browser blok asset http:// sebagai mixed content.
  Solusi: Tambah deteksi header Cloudflare di Constants.php baris 80:
    $https = isset($_SERVER['HTTPS']) && $_SERVER['HTTPS'] != 'off';
    $https = $https || (isset($_SERVER['HTTP_X_FORWARDED_PROTO']) && $_SERVER['HTTP_X_FORWARDED_PROTO'] === 'https');
    $https = $https || (isset($_SERVER['HTTP_CF_VISITOR']) && strpos($_SERVER['HTTP_CF_VISITOR'], '"https"') !== false);
    $base = ($https ? 'https://' : 'http://') . $_SERVER['HTTP_HOST'] . str_replace('\\','/', dirname($_SERVER['SCRIPT_NAME']));

MASALAH #3: Apache perlu restart
  Gejala: Perubahan Constants.php gak生效 sampai Apache di-restart
  Solusi: Buka CMD sebagai Administrator, jalanin:
    net stop httpd && net start httpd
  Atau:
    "C:\newappraporsd2025\serverapp\bin\httpd.exe" -k restart
