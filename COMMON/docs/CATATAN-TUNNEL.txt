#eraport #error500 #baseurl
==========================
MASALAH: HTTP 500 - Config\App::$baseURL not valid
  Gejala: E-Rapor error 500 via Cloudflare Tunnel
  Penyebab: dirname() di Windows hasilin backslash (\),
            URL jadi: http://domain.com\/ (gak valid)
  Lokasi: C:\newappraporsd2025\wwwroot\app\Config\Constants.php
  SOLUSI:
    $base = ... str_replace('\\','/', dirname($_SERVER['SCRIPT_NAME']));

==========================
#eraport #litmode #mixedcontent #css #https
==========================
MASALAH: Mode Lite (CSS/JS gak loading)
  Gejala: Halaman kebuka polos, tanpa styling
  Penyebab: Cloudflare kirim HTTPS ke user, HTTP ke server.
            PHP detek HTTPS=off, baseURL pake http://
            Browser blok asset http sebagai mixed content.
  SOLUSI: Constants.php:
    $https = isset($_SERVER['HTTPS']) && $_SERVER['HTTPS'] != 'off';
    $https = $https || (isset($_SERVER['HTTP_X_FORWARDED_PROTO']) && $_SERVER['HTTP_X_FORWARDED_PROTO'] === 'https');
    $https = $https || (isset($_SERVER['HTTP_CF_VISITOR']) && strpos($_SERVER['HTTP_CF_VISITOR'], '"https"') !== false);
    $base = ($https ? 'https://' : 'http://') . $_SERVER['HTTP_HOST'] . str_replace('\\','/', dirname($_SERVER['SCRIPT_NAME']));
