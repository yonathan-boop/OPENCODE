# Panduan Pakai Session AI Murah (Session Share)

Di-update: 5 September 2026
Sumber panduan penjual: Google Docs (dokumen tutorial login session AI)

## Apa Ini
Langganan "AI murah" = login session berbagi ke akun AI premium orang lain
(ChatGPT, Perplexity, Sider, dll). Cara pakai: ekstensi Chrome **Session Share**
yang menempel "kunci login" (cookie/session) dari penjual ke browser kita.

## Sistem: 1 Session = 1 Device
- Aturan penjual: MAX 1 device per session. Kalau dipakai 2 device bersamaan
  -> mutual kick / dicabut admin.
- Pindah device = "parse ulang" session di device tujuan (bukan nyalain 2 bareng).

## Keputusan (5 Sep 2026) — PAKAI DI DEVICE SENDIRI, BUKAN SERVER
- Browser Online di server Linux (noVNC) TERLALU LELET -> user tidak bisa pakai.
- Solusi pilihan: pakai Session Share LANGSUNG di HP & PC sendiri.
  - Chrome jalan di device user (enteng, ngebut), bukan distream dari VPS.
  - Server Linux TIDAK dipakai untuk Chrome.

## Cara Pakai

### HP Android (pakai Mises Browser)
1. Install **Mises Browser** (bisa pasang extension, Chrome Android tidak bisa).
2. Pasang extension **Session Share** di Mises.
3. Salin teks `session_paste ...` dari dokumen penjual (pilih produk).
4. Klik ekstensi Session Share -> **Parse session from clipboard** -> masuk akun.

### PC (Chrome)
1. Install extension **Session Share** dari Chrome Web Store.
2. Salin teks `session_paste` yang sama -> **Parse session from clipboard** -> masuk.
3. Ganti-ganti HP & PC: parse ulang session di device tujuan (jangan bareng).

## Peringatan Privasi & Risiko
- Session = akun orang lain. History chat bisa terlihat pemilik/pembeli lain.
- JANGAN taruh data sensitif (siswa, sekolah, NIK, dll) di chat AI berbagi ini.
- Bukan kontrak resmi -> bisa dicabut kapan aja / kena ban penyedia.
- Harga murah = akun sharing (grey area).
