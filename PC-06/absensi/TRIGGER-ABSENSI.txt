## CARA INPUT ABSENSI

1. Duplicate file ABSENSI Mei.xlsx ke nama baru (timestamp)
2. Buka file baru, edit langsung via openpyxl
3. Contoh formula:

```python

# Update TKa - row 7 (Aldrich), col 21 (tgl 18)
```
