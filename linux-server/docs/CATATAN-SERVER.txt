MASALAH: User sering tidak sengaja kill proses di terminal web karena muscle memory Ctrl+C (di terminal web Ctrl+C itu copy, tapi di Linux jadi SIGINT).
SOLUSI: Remap interrupt ke tombol lain.

  - Catatan: hanya berlaku untuk shell baru (sudah ada di .bashrc); Ctrl+K di bash readline tidak lagi delete-to-end-of-line karena dipakai sebagai SIGINT

DECISION: Install PowerShell DIBATALKAN oleh user ("ngk jadi").
