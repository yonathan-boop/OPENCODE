# Antigravity AI Workspace & Configuration

Folder ini adalah pusat konfigurasi, persona, task runbook, dan skills khusus untuk **Antigravity AI**.

## Struktur Folder

```text
antigravity/
├── README.md        # Ringkasan direktori
├── IDENTITY.md      # Identitas & kapabilitas sistem
├── SOUL.md          # Prinsip kerja & batasan operasional
├── USER.md          # Profil dan preferensi komunikasi user
├── TASKS.md         # Checklist alur kerja rutin
└── skills/          # Ekstensi kemampuan manipulasi dokumen
    ├── docx/        # Word manipulation skill
    ├── xlsx/        # Excel spreadsheet skill
    ├── pdf/         # PDF manipulation skill
    └── pptx/        # PowerPoint manipulation skill
```

## Sinkronisasi
Setiap pembaruan konfigurasi atau runbook di folder ini disinkronkan langsung ke repositori GitHub memori utama (`yonathan-boop/OPENCODE`).
